# もりさき臨床 v0.8.1

iPhoneファーストの診療記録試作品です。

## v0.8.1 の主な変更
- 患者を選んだ後に「患者カルテ」画面を表示
- 大きな「診療開始」ボタンを追加
- 前回の要点を診療前に確認
- 初診・再診を時系列で見られる診療タイムライン
- 診療画面に「観察→共通問診→急性・慢性→探索・施術→まとめ」の流れを表示
- 今日保存した診療記録をホームに表示
- v0.6系のテストデータを自動移行

## 注意
現在は操作確認用です。実在する患者情報は入力しないでください。GitHubにはプログラムだけを保存し、将来の実運用データは安全なデータベースへ分離します。


## v0.8.1
- フリガナ変換を入力中ではなく確定後に実行
- 「いつから」をタップ選択化
- 現在の状態をタップ選択化
- 日内変動、初期観察、危険徴候の確認記録をタップ選択化
