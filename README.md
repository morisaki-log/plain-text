# もりさき臨床 v0.6.1

## 今回の更新

- 患者登録に「〒 郵便番号から」ボタンを追加
- 郵便番号7桁から都道府県・市区町村・町域を自動入力
- ハイフンあり／なし、全角数字の郵便番号に対応
- 「地域を押して選ぶ」階層式住所入力を追加
- 九州 → 福岡県 → 北九州市 → 区 → 町域の順にタップ可能
- 北九州市周辺のよく使う地域を優先して収録
- 番地・建物名・部屋番号は別欄で手入力
- 選択肢にない住所は途中まで選択して直接追記可能
- iPhoneで最新版を読み込みやすいキャッシュ設定を更新

## 注意

郵便番号検索では郵便番号だけを住所検索サービスへ送信します。氏名・電話番号・診療情報は送信しません。

この版も操作確認用です。実在する患者情報は、正式な認証・暗号化・バックアップ・復元確認が整うまで入力しないでください。
